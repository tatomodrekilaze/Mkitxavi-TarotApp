# Contributing

This is a source release of a retired app. Fork it if you want to keep developing it.

Keep changes focused. Explain what changed and how you checked it. Run type checking, lint, and the build before proposing changes. Leave generated routing files to the router tooling.

Use your own development services. Never commit credentials, account exports, chats, uploaded user files, or database dumps. Use fictional records in examples.

Write interface text as you would explain a feature to a person. Keep English and Georgian translations aligned. Comments should explain decisions or constraints that are not obvious from the code.
